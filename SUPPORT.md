# Destek

Doğru kanalı seçmeniz yanıt ve çözüm süresini kısaltır:

| Konu | Kanal |
| --- | --- |
| Kurulum, kullanım veya sonuç yorumlama | [GitHub Discussions](https://github.com/trugurpala/turkiye-iban/discussions) |
| Tekrarlanabilir yazılım hatası | [Bug report formu](https://github.com/trugurpala/turkiye-iban/issues/new/choose) |
| Yeni özellik veya belge önerisi | [Feature request formu](https://github.com/trugurpala/turkiye-iban/issues/new/choose) |
| Resmî kuruluş verisi düzeltmesi | [Data correction formu](https://github.com/trugurpala/turkiye-iban/issues/new/choose) |
| Güvenlik açığı veya veri sızıntısı | [Özel GitHub Security Advisory](https://github.com/trugurpala/turkiye-iban/security/advisories/new) |

Bu proje bireysel IBAN, transfer, hesap sahibi, banka işlemi veya müşteri
hizmeti desteği vermez. Hesabınızla ilgili sorular için doğrudan bankanızla
iletişime geçin.

Issue, Discussion, PR, log veya ekran görüntüsünde gerçek IBAN, müşteri kaydı
ya da kişisel finansal veri paylaşmayın. Yeniden üretim için yalnız sentetik
örnek, kullandığınız sürüm, çalışma ortamı ve beklenen/gerçekleşen davranış
yeterlidir.
