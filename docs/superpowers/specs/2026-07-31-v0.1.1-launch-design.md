# v0.1.1 Lansman Tasarımı

## Amaç

`turkiye-iban` projesinin çalışan `0.1.0` çekirdeğini değiştirmeden; GitHub ve NPM yüzeylerini aynı, kullanıcı dostu anlatımda buluşturmak, projeye tutarlı tanıtım varlıkları kazandırmak ve ilk topluluk katkıları için görünür giriş noktaları açmak. Çalışma `tr-iban@0.1.1`, `v0.1.1` GitHub Release ve temiz `main` dalı ile tamamlanır.

## Başarı ölçütleri

- GitHub ve NPM, paketin ne yaptığını ve neyi doğrulamadığını aynı anlamla açıklar.
- Figma kaynak dosyasında GitHub, yatay sosyal paylaşım ve kare topluluk görselleri düzenlenebilir katmanlar halinde bulunur.
- Dışa aktarılan PNG dosyaları repoda sürümlenir ve GitHub sosyal önizlemesi olarak kullanılır.
- GitHub Discussions açık, başlangıç katkı issue'ları etiketli ve erişilebilir durumdadır.
- Türkçe lansman metinleri kopyalanıp yayımlanabilecek son haldedir.
- Ölçüm yalnız GitHub ve NPM'nin toplu istatistiklerine dayanır; pakete telemetri eklenmez.
- PR ve birleşme sonrası CI başarılıdır; GitHub Release ile NPM sürümü aynı `0.1.1` sürümünü gösterir.

## Kapsam

### Görsel sistem

Mevcut Figma dosyası `turkiye-iban · GitHub görsel sistemi` ve “Sayısal Müşterek” felsefesi ana kaynak olarak kullanılır. Görsel dil; IBM Plex Sans, IBM Plex Mono, doğrulama kırmızısı `#D42436`, kaynak petrolü `#087F8C`, topluluk altını `#E7B547`, mürekkep `#17202A` ve kâğıt `#F7F8FA` renklerini korur. İmza öğesi Türkiye IBAN yapısındaki `2 · 2 · 5 · 1 · 16` ritmidir.

Üretilecek Figma frame ve PNG çıktıları:

| Varlık | Ölçü | Kullanım |
| --- | ---: | --- |
| GitHub sosyal önizleme | 1280×640 | Depo bağlantısının sosyal ağ önizlemesi |
| Lansman yatay | 1200×675 | X ve LinkedIn paylaşımı |
| Topluluk kare | 1200×1200 | Topluluk ve proje paylaşım kanalları |

Her varlık açık arka planlı, logosuz ve resmî kurum görsel kimliğini taklit etmeyen özgün bir kompozisyon kullanır. “TCMB kaynaklı” ifadesi verinin kaynağını anlatır; TCMB onayı veya ortaklığı izlenimi vermez. Varlıklarda gerçek IBAN bulunmaz.

### README ve yayın anlatımı

Kök `README.md` projenin ana Türkçe girişidir. İlk ekranda amaç, sınır, kurulum ve doğrulanabilir veri kaynağı görünür kalır. Paket README'si aynı sözleşmeyi daha kısa biçimde taşır; kurulum, ilk kullanım, `unknown` sağlayıcı semantiği, format/checksum açıklaması, gizlilik uyarısı ve ana repo bağlantısı içerir. Kök README ile paket README arasında çelişkili API veya güvenlik ifadesi bulunamaz.

NPM sayfasındaki README yalnız yeni paket yayımlandığında değiştiği için `packages/typescript/README.md` güncellemesi `0.1.1` sürümüyle yayımlanır. Sürüm notu davranış değişikliği olmadığını; belge, görünürlük ve topluluk hazırlığı sürümü olduğunu belirtir.

### Topluluk yüzeyleri

GitHub Discussions etkinleştirilir. İlk duyuru, projenin amacı, resmî veri yaklaşımı, kullanım sınırı ve katkı çağrısını içerir. Aşağıdaki başlangıç issue'ları açılır:

1. Next.js/NestJS kullanım örneği: `documentation`, `good first issue`
2. PHP/Composer paketinin ilk fazı: `enhancement`, `help wanted`
3. Python paketinin tasarım hazırlığı: `enhancement`, `help wanted`
4. Makinece okunabilir veri fark raporu: `data`, `help wanted`

Issue'lar gerçek IBAN paylaşmama kuralını tekrarlar ve mevcut roadmap'e bağlanır. PHP/Python issue'ları tamamlanmış özellik izlenimi vermez.

### Lansman paketi

`docs/launch/` altında şu belgeler üretilir:

- `LAUNCH_GUIDE.md`: konumlandırma, hedef kitle, kanal sırası ve yayın kontrol listesi
- `SOCIAL_COPY.md`: X, LinkedIn, TurkDev/Reddit ve kısa mesaj sürümleri
- `OUTREACH_EMAIL.md`: topluluk yöneticilerine gönderilebilecek kişiselleştirilebilir e-posta taslağı
- `METRICS.md`: başlangıç, 7 gün ve 30 gün ölçüm tablosu ile komutlar

Tanıtım “reklam” dili yerine geliştirici sorununu, çözümü, resmî kaynak zincirini ve öğrenilen teknik kararları anlatır. Topluluklara otomatik ya da toplu mesaj gönderilmez. Gerçek gönderi, ilgili kanal kurallarına uyularak insan tarafından yayımlanır.

### Ölçüm

Başlangıç değerleri sürüm tarihinde kaydedilir. Takip edilen toplu ölçüler: GitHub görüntüleme, benzersiz ziyaretçi, clone, star, fork, issue ve katkıcı sayısı; NPM haftalık indirme sayısı. Kişi bazlı izleme, çerez, analitik SDK veya runtime telemetrisi eklenmez.

## Kapsam dışı

- IBAN doğrulama algoritmasını veya kuruluş veri modelini değiştirmek
- PHP/Composer ve Python paketlerini bu sürümde geliştirmek
- Ücretli reklam satın almak
- Kullanıcı adına izinsiz e-posta, forum veya sosyal medya gönderisi yayımlamak
- TCMB logosu, banka logosu veya resmî destek izlenimi kullanmak
- Gerçek IBAN, müşteri veya hesap sahibi verisi toplamak

## Yayın akışı

1. Görseller Figma'da hazırlanır, ekran görüntüsüyle incelenir ve PNG olarak dışa aktarılır.
2. README, lansman belgeleri, sürüm numarası, lockfile, roadmap ve changelog güncellenir.
3. Yerel test, mahremiyet taraması, paket içerik denetimi ve audit çalıştırılır.
4. Değişiklikler PR üzerinden Node 22/24 CI ile doğrulanır ve squash merge edilir.
5. `v0.1.1` etiketi `main` üzerindeki sürüm commit'ine oluşturulur; release workflow JSON/CSV/SQL, paket, SBOM ve checksum varlıklarını yayımlar.
6. NPM trusted publishing workflow'u `latest` etiketiyle çalıştırılır. OIDC provenance otomatik oluşur.
7. GitHub ve NPM sayfaları, görseller, sürümler, provenance, issue/discussion yüzeyleri ve temiz worktree ayrı ayrı doğrulanır.

## Hata ve geri alma yaklaşımı
