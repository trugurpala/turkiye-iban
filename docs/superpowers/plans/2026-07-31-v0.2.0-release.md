# v0.2.0 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish and verify GitHub Release `v0.2.0` and NPM package `tr-iban@0.2.0` with synchronized documentation, Figma visuals and reproducible assets.

**Architecture:** Release preparation changes metadata and public copy without altering runtime behavior or institution data. Publication is gated in order: source review, local verification, PR CI, GitHub tag/release, NPM trusted publishing, then clean-consumer and checksum verification.

**Tech Stack:** TypeScript, NPM workspaces, Python 3.12, sql.js WebAssembly, GitHub Actions/CLI, Figma Plugin API.

## Global Constraints

- Keep all seven public API functions and the 70-record canonical dataset unchanged.
- Use only synthetic IBAN examples and never print an unrecognized IBAN candidate.
- Do not publish NPM before the matching immutable GitHub Release exists.
- Preserve Divan attribution; Divan and sql.js remain non-runtime tooling.
- Stop publication when source review, CI, checksum or version/tag verification fails.
