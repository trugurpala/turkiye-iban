# v0.1.1 Lansman Uygulama Planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use core-pack:subagent-driven-development (recommended) or core-pack:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `turkiye-iban` projesinin Figma varlıklarını, GitHub/NPM anlatımını, topluluk giriş noktalarını ve ölçüm belgelerini tamamlayıp doğrulanmış `v0.1.1` GitHub Release ile `tr-iban@0.1.1` NPM sürümünü yayımlamak.

**Architecture:** Çalışan IBAN API'si ve veri modeli değişmeden kalır. Görsel kaynak Figma'da, sürümlenen PNG çıktıları `docs/assets/` altında; kullanıcı anlatımı README dosyalarında; lansman ve ölçüm operasyonu `docs/launch/` altında tutulur. Yayın yalnız korumalı `main`, GitHub Actions Release ve NPM trusted publishing zincirinden yapılır.

**Tech Stack:** Figma Plugin API, Markdown, GitHub CLI/API, GitHub Actions, Node.js 22/24, TypeScript, Python doğrulama araçları, NPM trusted publishing.

## Global Constraints

- Runtime API davranışı ve `data/` içeriği değişmeyecek.
- Gerçek IBAN veya kişisel finansal veri hiçbir varlığa girmeyecek.
- TCMB logosu veya resmî ortaklık izlenimi kullanılmayacak.
- Paket runtime telemetrisi veya yeni runtime bağımlılığı eklenmeyecek.
- Görsel kaynak dosyası `1pFu8ImZ4oO7KfhZzMKdIR` olacak.
- Sürüm `0.1.1`; GitHub etiketi `v0.1.1`; NPM dist-tag `latest` olacak.
- Tüm kod ve belge değişiklikleri PR ve zorunlu Node 22/24 CI üzerinden birleşecek.

- [ ] **Step 4: PNG dosyalarını dışa aktar ve ölçüleri doğrula**

Run:

```powershell
Add-Type -AssemblyName System.Drawing
Get-ChildItem docs/assets/github/social-preview.png,docs/assets/launch/*.png | ForEach-Object {
  $image = [System.Drawing.Image]::FromFile($_.FullName)
  try { "{0} {1}x{2}" -f $_.Name,$image.Width,$image.Height } finally { $image.Dispose() }
}
```

Expected: sırasıyla `1280x640`, `1200x675`, `1200x1200`.
